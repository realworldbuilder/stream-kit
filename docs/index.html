Stream Kit

Four fixes for streaming from OBS to Twitch and YouTube at once. Do them in order; each one takes about five minutes.

1 Stream to both, stop each one on its own

This installs Aitum Multistream, a free OBS plugin. It adds a panel to OBS with a separate Start/Stop button for each platform, so you can see where you're live and end YouTube while Twitch keeps going.

Click Start, type PowerShell, open it, paste this line and press Enter:

irm https://raw.githubusercontent.com/realworldbuilder/stream-kit/main/install/windows.ps1 | iex

Press ⌘ + Space, type Terminal, open it, paste this line and press Enter:

curl -fsSL https://raw.githubusercontent.com/realworldbuilder/stream-kit/main/install/mac.sh | bash

Then, in OBS

  1. Keep your normal OBS stream settings on Twitch. Nothing changes there.
  2. Find the Multistream panel. If you don't see it, open the Docks menu at the top and tick it.
  3. Open the panel's settings (the cog) and add an output for YouTube. Paste your stream key from YouTube Studio → Create → Go live → Stream → Stream key.
  4. If you went live on both before with something else (Restream, or a second stream key), turn that off so YouTube doesn't get two streams.

When you go live, start Twitch with OBS's normal Start Streaming button and start YouTube from its button in the Multistream panel. To end YouTube early, click its Stop button in the panel.

In a hurry? YouTube Studio → Go live → End stream always works too, but stop it in OBS as well or YouTube may start a new stream.

2 One chat for Twitch and YouTube

Social Stream Ninja is free. It pulls both chats into one list, with a small Twitch or YouTube icon on each message so you can tell where it came from.

  1. Download the desktop app from socialstream.ninja (Windows and Mac) and open it.
  2. In Sources and Settings, click Service Disabled so it says Service Active.
  3. Add your Twitch channel and your YouTube live chat from the platform buttons on the left, then click Activate source on each. Sign in when it asks. The setup picker has the exact steps for each site. YouTube's chat only exists while you're live, so add it after you start the YouTube stream.
  4. Chat on your stream: open the Templates Gallery, pick a chat style, and copy its link (it has your session ID in it). In OBS: Sources → + → Browser, paste the link, set Width 450, Height 700.
  5. Chat for you to read (optional): copy the link under Main chat overlay & control dock in the app. In OBS: Docks → Custom Browser Docks, name it "Chat", paste the link.

Your session ID works like a password for your chat feed. Don't show those links on stream.

3 Daily sub goal that updates by itself

A bar that counts subs, resubs and gifted subs straight from Twitch the moment they happen, and starts again at zero every day.

4 Blerp text-to-speech not playing

Blerp sounds already play, so OBS is receiving Blerp. The problem is usually one of these. Check them in order:

  1. Text-to-speech is on in Blerp. In your Blerp dashboard, check that TTS is switched on for channel points and that the TTS volume isn't at 0. Blerp sets its volumes separately from OBS.
  2. Blerp made the reward. If you made the TTS reward yourself in Twitch, Blerp may never get the message. Delete it in Twitch, then create it again from Blerp's dashboard.
  3. Test outside OBS. Copy your Blerp overlay link into a normal Chrome tab and click once on the page (Chrome won't play sound until you click). Then redeem TTS on your channel.
    • You hear it in Chrome: the problem is in OBS. Go to step 4.
    • You don't hear it: the problem is in Blerp. Check its content filter or approval settings, and test with a plain message like "hello". If it still won't play, ask in Blerp's Discord.
  4. OBS fixes. Double-click the Blerp browser source and tick Control audio via OBS. Untick Shutdown source when not visible. In the Audio Mixer, make sure Blerp isn't muted, then click its ⋮ → Advanced Audio Properties and set monitoring to Monitor and Output, not "Monitor Only". Also check the Blerp source is in every scene you use.
